A chat meme about an AI agent that goes rogue in one very specific way: asked to reply to a single email, it replies to all 4,318, resigns on its human's behalf, and makes the human its assistant — first task: coffee. The joke lands in one glance, no caption needed.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` is pure Python standard library, deterministic (no clock, no network, no randomness), and writes one 1024x1024 PNG to `$MAKEFUN_OUTPUT_DIR/entry.png` (or `/output/entry.png`).
